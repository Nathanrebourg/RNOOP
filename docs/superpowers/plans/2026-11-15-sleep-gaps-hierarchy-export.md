# Sleep support, hierarchical experiment and native diagnostic export

User-authorized scope: expose unobserved periods, test a two-step sleep classifier, export a replayable
night from iPhone, and audit official WHOOP capabilities against real NOOP call sites. Existing score
defaults and stored stage contracts remain unchanged until physiological validation supports promotion.

1. Add a bounded Swift/Kotlin 30-second availability mask. Unknown is distinct from wake/light and from
   low confidence. Preserve partial edges; duplicates and delivery order do not add availability. Compile
   actual Swift oracle and pin literals in Kotlin and reverse Swift tests.
2. Add the hierarchical wake/sleep then light/deep/REM classifier in the SleepPSG research executable.
   Freeze the method before measuring; reuse V2 emissions and enforce shipped-port equivalence. Evaluate
   existing 47 public first nights retrospectively; the prior 30/17 split has already been inspected.
   Report coverage, per-participant metrics and abstentions; no untouched-holdout claim or promotion.
3. Add user-triggered native Apple export with strict source ownership, bounded read-only capture,
   consistency checks, compatible recording, separate persisted app snapshot, provenance and hashes.
   Include signal support and a preview. Refuse unsupported day/source rather than silently approximating.
   Add exact-member, hash-checked diagnostic ZIP replay support to local tools.
4. Audit official WHOOP documentation against actual implementation and hardware constraints (WHOOP 5.0,
   not MG). Separate absent, partial, experimental, differently defined and out-of-scope capabilities.
5. Run focused and package tests, Swift/Kotlin oracle, native replay roundtrip, iPhone/macOS app builds,
   and independent code review. Package source, tools, reports, patch and a rebuilt iPhone IPA.

Independent implementation domains: shared coverage/replay integration (root), SleepPSG hierarchy,
native Apple export, and read-only WHOOP audit. No new sensor writes, cloud dependency or migration.
