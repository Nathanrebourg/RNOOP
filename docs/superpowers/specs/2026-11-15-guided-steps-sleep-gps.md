# Guided capture and optional physiology research

The user selected axes1,3,4 after the local-improvement release and confirmed the proposed Start/Finish
walking buttons. Existing12.3 calibration is manual; the next version adds a separate guided flow.

Guided walks: freeze owner and start/end timestamps on button presses, require still boundary intervals,
read exactly one registered liveWHOOP5 source after normal synchronization, bound reads, reject changed
snapshots, ambiguous counter decreases, gaps and every increment the incumbent pipeline would discard.
User-counted steps remain an explicit manual observation. Persist at most8 accepted trial metadata plus
one pending window locally, not raw streams, so navigating to sync does not lose a calibration. Decode
and save are bounded/validated; only explicit Apply changes the existing scale. No Bluetooth command.

Sleep experiment: opt-in research screen compares declared clock regularity, sufficiency/efficiency and
bounded source-qualified nocturnal activation proxy with the incumbent. Weights and workflow thresholds
are frozen before observation, missing components are never reweighted into a seemingly complete result.
No cached night is assumed to have valid RR provenance. Read real bounded raw evidence where available;
otherwise withhold. No claim of sleep-stage validation from a composite comparison, and no promotion.

ExerciseGPS: first qualify actual timestamped route and HR evidence. Published protocol-specific models
must match their population, units and input protocol; generic runs cannot become VO2max by a guessed
oxygen-cost conversion. Preserve trueVO2max, vVO2max and observed efficiency as distinct quantities.
Unverifiable formulae or unsupported protocol metadata produce an explicit refusal, not a new score.

Each numerical kernel has Swift/Kotlin twins and actual compiled bilateral oracles. Native adapters use
real in-memory store tests; main app builds must pass on iPhone and macOS. No new store migration,
account, network dependency, firmware operation, automatic medical advice or default score replacement.
